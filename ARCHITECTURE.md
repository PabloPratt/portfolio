# Portfolio architecture

This is Pablo Pratt's portfolio, built with Next.js 16, React 19, TypeScript, and Tailwind CSS.

## Pages

- Home, work, about, leadership, hobbies, contact, consulting, writing, reading, and now.
- The work page lists Janus, AUTONOMY, Loki, DOOOD, and ATX Services Scout. Each links to an external application.
- The specialized tool directory, demo widgets, AI tool endpoints, and their pricing, dashboard, and account pages have been removed.
- Legacy Stripe endpoints and supporting integrations remain outside this content cleanup.

## Checks

- Build: `npm run build`
- Lint: `npm run lint`
- No test script or test files are present.

See [CONTENT-CLEANUP.md](CONTENT-CLEANUP.md) for removals, remaining external URLs, and validation limits.
